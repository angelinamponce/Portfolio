# Logo sources

Downloaded 2026-10-19 from each organization's own website. Files are byte-for-byte as served,
except ey.svg (see below). None were redrawn, traced or recoloured; the strip tints them with CSS.

| File | Source | Notes |
|---|---|---|
| cpc.png | https://communityp.com/wp-content/uploads/2025/08/cpc-logo-2015_color-scaled.png | 2048×1024 PNG, transparent (alpha 1/255 background). CPC's site offers no SVG; its header PNG (CPC_logo.png) has an opaque white background, so it was not used. |
| brightshore.svg | https://brightshore.com/Brightshore-logo.svg | Header logo of brightshore.com (gtispartners.com redirects there). New Brightshore Capital mark, not the GTIS logo. |
| hackmit.svg | https://hackmit.org/assets/logo.svg | Logo referenced by hackmit.org's site bundle. Not the MIT institutional logo. |
| colorstack.png | https://cdn.prod.website-files.com/61ae4846c32bb55b23085ccd/621150da29e6f9048c44a6dd_Logo.png | Header logo of colorstack.org, 422×64 PNG with a transparent background. No SVG offered. |
| ey.svg | Inline SVG in the footer of https://www.ey.com/en_us (`#footer-ey-logo-image-1`) | Copied verbatim; the only addition is `xmlns="http://www.w3.org/2000/svg"`, which a standalone SVG file needs. Includes EY's "Shape the future with confidence" tagline, as on ey.com. |
| barclays.svg | https://home.barclays/content/dam/home-barclays/images/generic/barclays-wordmark.svg | Barclays wordmark from home.barclays' header (the header pairs it with a separate eagle file). |
